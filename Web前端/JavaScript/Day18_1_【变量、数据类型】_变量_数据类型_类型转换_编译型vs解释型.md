## 1. 变量声明与命名规范

### 1.1 变量的定义与使用

JavaScript 中使用 `var` 关键字声明变量，JS 为其自动分配内存空间。

- 格式：
  - **声明：**`var 变量名;`
  - **变量初始化：**`var 变量名 = 值;`
  - 多变量声明：`var a = 10, b = 'abc', c = true;`
- 未赋值变量默认值为 `undefined`

> 💡 上述示例中的 `10`、`'ABC'`、`true` 等直接写在代码中的值，称为**字面量（Literal）**。

### 1.2 命名规则

- 遵循小驼峰命名（如：`myVariableName`）
- 变量名区分大小写（`aA` 与 `aa` 是不同变量）
- **避免：**以数字开头、使用关键字（如 `var`、`let`、`for` 等）

> ⚠️ **避免直接使用** `a = 10`（未使用 `var/let/const`）会自动创建全局变量，虽合法但极不规范。

## 2. 数据类型体系

### 2.1 JS 类型系统概览

- JavaScript 是**弱类型、动态类型语言**
- 所有变量在运行时根据值推断类型，不需提前指定
- 数据类型分为两大类：

| 分类       | 子类型说明                                                     |
|------------|----------------------------------------------------------------|
| 简单类型   | Number, String, Boolean, Undefined, Null                      |
| 复杂类型   | Object（包括数组、函数、对象字面量等）                        |

> 可以通过 `typeof` 关键字判断数据的类型

---

### 2.2 简单数据类型

#### 1. Number 类型

- 支持整数与浮点数
- 三个特殊值：
  - `Infinity`：正无穷大
  - `-Infinity`：负无穷大
  - `NaN`（Not a Number）表示非法的数值运算结果，可通过 `isNaN(val)` 判断是否为 `NaN`。

#### 2. String 类型

- `.length`：获取字符串长度。
- 字符串拼接：通过 `+` 运算符拼接。但每次拼接都会创建新的字符串对象，而非在原字符串上修改。
- **转义符：**常用转义符用于表示字符串中的特殊字符，适用于控制格式、嵌套引号等场景：

| 转义符 | 说明   |
| ------ | ------ |
| `\`    | 反斜杠 |
| `\'`   | 单引号 |
| `\"`   | 双引号 |
| `\t`   | 缩进   |
| `\n`   | 换行   |

#### 3. Boolean 类型

Boolean 表示逻辑状态，只有 `true` 和 `false` 两个值，可参与数值运算并常用于条件判断（ `true=1`、`false=0`）。

```js
true + 1    // 2
false + 1   // 1
```

#### 4. Undefined 类型

undefined 表示“声明未赋值”，可参与运算但极易引发异常，应在使用前显式判空。如下所示：

```js
let a;
console.log(a);         // undefined
a + 'abc';              // 'undefinedabc'
a + 22;                 // NaN
a + false;              // NaN
```

#### 5. Null 类型

null 表示“主动赋空”，用于占位对象引用，可参与运算但结果受上下文影响，常用于初始化或重置状态。

```js
'你好' + null    // '你好null'
11 + null        // 11
true + null      // 1
```

### 2.3 复杂数据类型

#### Object 对象类型

- 用于表示复合结构（键值对）

```js
let person = { name: 'Tom', age: 20 };
```

## 3. 数据类型转换

### 3.1 转为 String

| 方法                 | 说明                           |
|----------------------|--------------------------------|
| `toString()`         | 对象方法，部分类型不可用（如 `null`） |
| `String(val)`      | 强制转换，通用安全           |
| 字符串拼接：`+`      | 自动触发隐式转换                 |

### 3.2 转为 Number

| 方法                      | 说明                 |
| ------------------------- | -------------------- |
| `parseInt()`              | 只保留整数部分       |
| `parseFloat()`            | 保留小数             |
| `Number()`                | 强制转换为数字       |
| 隐式转换（`-`，`*`，`/`） | 自动将参与值转为数字 |

> `+` 是唯一具有拼接语义的运算符，遇字符串优先执行拼接；其余运算符一律执行数值转换。

### 3.3 转为 Boolean

| 方法           | 说明                       |
| -------------- | -------------------------- |
| `Boolean(val)` | 强制将任意类型转换为布尔值 |

- 所有数据类型都可以转换为布尔类型。JS 中只有 8 个 `false` 值（包括 `false` 本身），其余所有值强制转换后均为 `true`。
  - **假值：**`false`，`0`，`-0`，`""`，`null`，`undefined`，`NaN`，`0n`
  - **真值：**除了上述 8 个值，其它全部为 `true`

## 4. 编译型语言 vs 解释型语言

判断一门语言是编译型还是解释型，最直接的标准是：**运行前是否需要将代码完整编译为机器码。**

- **编译型语言**（如 Java）在程序运行前会先使用编译器将源代码转换为中间代码或机器码，生成可执行文件，之后由操作系统直接运行。
- **解释型语言**（如 JavaScript）在执行时由解释器逐行读取并即时解释执行，无需提前编译。

---

## ✅ 总结

- JavaScript 是弱类型、动态类型、解释型语言。
- 所有变量类型在运行时决定，数据类型分原始类型与引用类型。
- 类型转换有三类：转字符串、转数字、转布尔，`+` 是唯一特殊运算符。
- 判断数据类型用 `typeof`，字面量是代码中直接写出的值。
- 区分编译/解释型语言的关键：是否在运行前整体编译为机器码。
