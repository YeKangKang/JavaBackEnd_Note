| 类型       | 运算符                                      | 说明                 |
|------------|---------------------------------------------|----------------------|
| 算术运算符  | `+ - * / % ++ --`                         | 基本数学运算         |
| 比较运算符  | `< > <= >= == != === !==`                   | 返回布尔值判断结果   |

## 2. 浮点精度问题

JavaScript 中某些十进制小数无法精确表示为二进制，会被截断，导致计算出现精度误差：

- 不建议直接比较两个浮点数是否相等

- 可使用“升位再降位”方式处理

```js
console.log(0.1 + 0.2); // 0.30000000000000004
let result = (0.2 * 10 + 0.1 * 10) / 10; // 0.3，升位再降位以抵抗精度损失
```

## 3. `++` / `--` 运算符详解

`++` / `--` 有前缀与后缀形式，参与表达式时顺序不同：

- **后缀自增 `a++`**：先使用原值，再自增（**先用再变**，结果返回原值）
- **前缀自增 `++a`**：先自增，再使用（**先变再用**，结果返回新值）

```javascript
var a = 10;
var b = a++ + ++a; // 10 + 12 = 22
```

> 后缀 `a++` 在表达式中使用后即自增，不是“整行结束后再变”。

---

## 4. `===` / `!==` 运算符详解

JS 为弱类型语言，支持全等运算符 `===` 和不全等 `!==`，要求**值和类型均一致**。

```js
37 === '37';  // 全等比较，返回 false
37 == '37';   // 值相等比较，返回 true（JS 会对 String 类型进行自动转换后再比较）
```

---

## 5. 短路运算

短路逻辑运算：一旦逻辑运算符左侧表达式已满足判断条件，短路逻辑运算符将**立即返回左侧值**，并跳过右侧表达式的执行。

```js
NaN && 456; // 返回 NaN，不再执行后续表达式（短路）
```

> 短路机制不仅用于逻辑判断，也常用于条件执行、兜底赋值等语法糖优化

---

## ✅ 总结

- 算术、比较、逻辑、赋值等运算符是 JS 表达式的基础
- 自增/自减在表达式中的执行顺序需特别注意
- 浮点数涉及精度问题，建议使用整数计算规避误差
- 逻辑运算符具备短路行为，是 JS 中常见的控制执行技巧
- JS 中允许弱类型比较，需注意 `==` 与 `===` 的语义差异
