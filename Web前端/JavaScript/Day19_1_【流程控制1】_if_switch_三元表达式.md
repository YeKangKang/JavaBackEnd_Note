# Day19 · JavaScript 基础（if、switch、三元表达式）

## 1. if / else if / else

`if/else if/else` 是**排他性结构**，适用于多条件的多选一判断：

- 条件按顺序从上到下判断
- **一旦某个条件成立，后续所有判断不再执行**
- 仅 `if/else if/else` 结构具备此“单选一”特性，多个独立 `if` 是并行判断

```js
if (条件1) {
  // 条件1成立时执行
} else if (条件2) {
  // 条件2成立时执行
} else {
  // 所有条件都不成立时执行
}
```

---

## 2. 三元运算符（简化版 `if/else`）

```js
let 变量 = 条件 ? 表达式A : 表达式B;

var score = 80;
var result = (score >= 60) ? "及格" : "不及格";	// result = “及格”
```

- 条件为真：返回 `表达式A`
- 条件为假：返回 `表达式B`

> 常用于简洁地根据条件选择赋值或输出，等价于简化版 `if/else`

---

## 3. switch 分支控制

`switch` 是多分支控制语句，适用于**已知值范围内的判断选择**。其判断机制为：

- 表达式的值与各 `case` 进行匹配
- 匹配使用 `===`（**全等判断**），值与类型必须一致才会命中
- 默认每个 `case` 后应添加 `break`，避免“穿透”（fall-through）

```js
switch (表达式) {
  case 值1:
    // 匹配值1时执行
    break;
  case 值2:
    // 匹配值2时执行
    break;
  default:
    // 所有 case 不匹配时执行
}
```

> 若需多个 `case` 执行相同逻辑，可省略中间的 `break` 实现穿透效果

---

## ✅ 总结

- `if/else if/else`：处理多条件判断，结构清晰，适合少量分支
- 三元表达式：适合简化版赋值逻辑
- `switch`：用于明确值匹配的多分支场景，可读性强，适用于 case 多但值明确的情况
