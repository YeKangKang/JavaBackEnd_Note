# Day17 · JavaScript 基础（语法构成、书写位置、输入输出）

---

## 1. JavaScript 简介

JavaScript 是一种运行在客户端的脚本语言，具有以下特点：

- **脚本语言**：无需编译，由浏览器内置的 JS 引擎逐行解释执行
- **用途广泛**：最初用于表单验证，后发展为网页特效、服务器端（Node.js）、桌面程序等

---

## 2. HTML / CSS / JS 关系

- `HTML`：定义页面的**结构与语义**
- `CSS`：负责**样式与视觉**呈现
- `JavaScript`：实现**交互逻辑**与**功能行为控制**

三者相互配合，共同构成现代网页。

---

## 3. 浏览器执行机制

现代浏览器主要由两部分组成：

| 组件       | 说明                                                         |
|------------|--------------------------------------------------------------|
| 渲染引擎（内核） | 负责解析 HTML、CSS 并绘制页面                               |
| JavaScript 引擎 | 负责解析和执行 JS 脚本（如 V8、SpiderMonkey）             |

> 浏览器中的JS引擎会逐行解释 `<script>` 标签中的代码。

---

## 4. JavaScript 的组成

JavaScript 由以下三部分构成：

| 组成部分     | 说明 |
|--------------|------|
| `ECMAScript` | JS 的语法规范和语言标准（如变量、函数、控制语句等） |
| `DOM` | **文档对象模型** (Document Object Model)，用于操作网页中的 HTML 元素 |
| `BOM` | **浏览器对象模型** (Browser Object Model)，用于与浏览器窗口交互，如弹窗、跳转等 |

---

## 5. JS 代码的书写位置

JavaScript 可以出现在 HTML 的以下位置：

### 5.1 行内式

将 JS 写在 HTML 标签的事件属性中：

```html
<button onclick='alert("Hi")'>点击</button>
```

- 内部使用单引号，避免与 HTML 双引号冲突
- 仅适用于非常简短的逻辑代码

### 5.2 内嵌式（script 标签）

通过 `<script>` 标签直接书写 JS 代码：

```html
<script>
  console.log("页面加载");
</script>
```

- `<script>` 可写在 `<head>` 或 `<body>` 中
- 若写在 `<head>` 中，推荐添加 `defer` 避免阻塞渲染
- 若写在 `<body>` 中，推荐放在尾部，确保 DOM 元素已加载

### 5.3 外部文件（推荐）

将 JS 独立至 `.js` 文件中，再通过 `src` 引入：

```html
<script src="main.js"></script>
```

- 推荐写在 `</body>` 前，或配合 `defer` 放在 `<head>` 中
- 注意：一旦使用 `src`，标签内部的 JS 内容将被忽略

---

## 6. 注释语法

与 Java 相同，JS 支持：

```js
// 单行注释

/*
 多行注释
*/
```

---

## 7. 常用输入 / 输出方法

| 方法             | 说明                               |
|------------------|------------------------------------|
| `alert(msg)`     | 弹出警示框，常用于提示用户信息     |
| `console.log(x)` | 在浏览器开发者工具中输出调试信息   |
| `prompt(msg)`    | 弹出输入框，获取用户输入（返回字符串或 null） |

---

## ✅ 总结

- JS 是运行在浏览器中的脚本语言，负责逻辑与交互
- 三大组成部分：ECMAScript（语法）+ DOM（操作页面）+ BOM（操作浏览器）
- 推荐将 JS 写在页面底部或使用 `defer`，以避免阻塞页面或绑定失败
- 输入输出常用 `alert`、`prompt`、`console.log` 等内置函数
