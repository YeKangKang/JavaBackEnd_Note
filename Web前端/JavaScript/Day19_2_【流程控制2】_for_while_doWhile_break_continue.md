# Day19 · JavaScript 基础（for、while、do-while、break、continue）

## 1. for 循环

适用于已知循环次数的情况，通过维护一个循环变量控制循环：

```js
for (初始化; 条件表达式; 操作表达式) {
  // 循环体
}
```

- 初始化：声明并初始化循环变量（如 `let i = 0`）
- 条件表达式：每轮循环前进行判断，结果为 `true` 则继续
- 操作表达式：每轮循环结束后执行，用于更新循环变量（如 `i++`）

---

## 2. while 循环（先判断，再执行）

适用于循环次数不确定、依赖外部条件控制的场景：

```js
while (条件表达式) {
  // 循环体
}
```

- 每轮循环前先判断条件是否成立
- 若第一次判断为 `false`，**将不会进入循环**

---

## 3. do...while 循环（先执行，再判断）

至少执行一次循环体，适用于需要先执行操作再判断条件的情况：

```js
do {
  // 循环体
} while (条件表达式);
```

- 不管条件是否成立，**循环体会先执行一次**

---

## 4. break & continue

### break：终止整个循环结构

当满足某一条件时，可用 `break` 强制退出当前循环：

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) break;
  console.log(i);
}
// 输出 0, 1
```

- 常用于提前退出循环
- 执行到 `break` 时，整个循环直接结束

---

### continue：跳过当前轮，进入下一次循环判断

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i);
}
// 输出 0, 1, 3, 4
```

- `continue` 会跳过当前循环中 `continue` 之后的语句

- 循环并不会结束，而是进入下一轮判断

> ⚠ 若在 `continue` 之前没有更新循环变量，可能导致死循环

---

## ✅ 总结

- `for`：适用于已知循环次数，结构紧凑，常用形式
- `while`：先判断条件，适合循环次数不确定场景
- `do...while`：先执行后判断，至少执行一次
- `break`：直接终止整个循环
- `continue`：跳过本轮，继续下一轮（注意更新循环变量）
