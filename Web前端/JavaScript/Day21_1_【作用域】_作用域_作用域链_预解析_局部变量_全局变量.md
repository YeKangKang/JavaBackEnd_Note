# Day21 · JavaScript 基础（作用域、作用域链、预解析）

## 1. 作用域概念

作用域定义了代码或变量的可用范围。超出该范围，变量不可访问。

- 有助于提升逻辑清晰度、避免命名冲突
- JS 共有三种作用域类型：**全局作用域、局部作用域（函数作用域）、块级作用域（ES6 引入）**

---

## 2. 各类作用域

### 2.1 全局作用域

- 作用于所有 JS 代码，包括页面中所有 `<script>` 标签及引入的 JS 文件
- 在全局作用域下声明的变量（**全局变量**）可被任意函数访问

```js
var a = 100;	// 全局变量
console.log(window.a); // 100
```

---

### 2.2 局部作用域（函数作用域）

- 在函数内部使用 `var` / `let` / `const` 声明的变量，**只在函数内部可见**
- 函数执行完毕后局部变量销毁（**局部变量**）

```js
function test() {
  var x = 10;	// 函数内部声明的局部变量
}
console.log(x); // ❌ 报错：x is not defined
```

---

### 2.3 块级作用域（ES6 引入）

- 使用 `let` / `const` 在 `{}` 中声明变量，会创建块级作用域
- `var` 不具备块级作用域（其声明会“穿透”代码块）

```js
{
  let b = 20;
}
console.log(b); // ❌ 报错，b 是块级作用域内的变量

{
  var a = 10;	// var 声明会穿透块级作用域
}
console.log(a); // ✅ 10
```

---

## 3. 全局变量 vs 局部变量

| 类型         | 说明                                                     | 生命周期           |
| ------------ | -------------------------------------------------------- | ------------------ |
| **全局变量** | 在函数外部使用 `var` 声明，或函数内部不加关键字直接赋值  | 页面关闭前始终存在 |
| **局部变量** | 函数内部声明的变量，或块级作用域内用 `let`，`const` 声明 | 代码块执行完即销毁 |

> 💡 使用未加关键字的变量（如 `num = 10`）会创建 **隐式全局变量**，应避免使用。

---

## 4. 作用域链（Scope Chain）

作用域链描述了 JS 变量查找的过程：

- 查找变量时，会从**当前作用域逐层向外查找，直到找到为止**
- 若到达全局作用域仍找不到，则抛出 `ReferenceError`

```js
var num = 333;

function outer() {
  var num = 222;	// 逐层向外查找，这里的 num 是“距离”最近的
  function inner() {
    console.log(num); // 从当前作用域逐层向外查找，num = 222（就近原则）
  }
  inner();
}
outer();
```

---

## 5. 预解析（Hoisting）

JS 执行前会进行一轮“预解析”，将变量声明和命名函数提前至**当前作用域顶部**。

### 5.1 `var` 提升

- **仅提升声明**，不提升赋值
- 提前访问时值为 `undefined`，不会报错

```js
console.log(x); // 仅声明提升，值 = undefined
var x = 10;
```

---

### 5.2 命名函数提升

- **函数名 + 函数体整体被提升**，可在声明前调用

```js
sayHi(); // 整体提升，Hello

function sayHi() {
  console.log("Hello");
}
```

---

### 5.3 函数表达式 / 箭头函数（不提升）

- 变量名可能提升（`var`），但值是 `undefined`
- **函数表达式**，**箭头函数**不可在声明前调用

```js
greet(); // 报错：greet is not a function

var greet = function () {
  console.log("Hi");
};
```

---

## ✅ 总结

- JS 中作用域分为：全局、函数、块级（ES6）
- 变量访问顺序遵循**作用域链（就近原则）**
- 仅 `var` 和命名函数声明具备提升机制
- 块级作用域必须用 `let/const` 声明才生效；`var` 无块级作用域能力
