# Day14 · CSS基础（组合选择器、序选择器）

本章介绍 CSS 中常见的**组合选择器**与**伪类结构性选择器**（序选择器）。组合选择器通过结构或条件组合多个基础选择器实现更精准的选中目标，序选择器用于选中某个元素在其父元素中处于特定位置时的情况。

---

## 1. CSS 高级选择器分类概览

### 📌 本章关注两类：

- **组合选择器**：后代选择器、交集选择器、并集选择器、子代选择器、相邻兄弟选择器等
- **伪类选择器（结构型）**：目前仅学习了结构型序选择器

> CSS 为组合型 DSL，选择器组合方式近乎无限，无需死记，只需掌握基本规则与结构逻辑即可。

---

## 2. 组合选择器

组合选择器指多个选择器通过结构或条件组合选中元素的方式，可实现精准的样式控制。

### 2.1 后代选择器（空格）

```css
div .className {	/* 选中所有位于 div 元素内部、class 为 className 的元素 */
  color: red;
}
```

- **空格表示“结构上的后代关系”**，不限于直接子代，任何嵌套层级都匹配
- 适合用于模块内部局部样式控制

---

### 2.2 交集选择器（并列写法）

```css
p.warning {
  color: red;	/* 选中所有 p 标签，且 class 为 warning 的元素 */
}
```

- 选中**同时符合多个选择条件的元素本身**，如同时具有特定标签和类名
- 顺序敏感，应写作“结构大 → 条件小”的组合，例如：`标签 + 类`、`标签 + 属性`，不能写成 `.warningp`

---

### 2.3 并集选择器（逗号分隔）

```css
div, .p1, a {	/* 选中所有 div 元素、p1 类元素、a 元素 */
  color: red;
}
```

- 匹配**所有满足任意一个选择器**的元素（逻辑“或”）
- 适用于多个类型/结构统一样式设置

---

### 2.4 子代选择器（`>`）

```css
div > p {	/* 选中所有 p 元素，前提是它是某个 div 元素的直接子元素 */
  color: red;
}
```

- **只匹配一层嵌套**，多层不会生效（孙子辈不匹配）
- 推荐用于结构严格、排版清晰的布局控制

---

### 2.5 相邻兄弟选择器（`+`）

```css
h3 + p {	/* （选中所有）仅当 h3 后紧跟的兄弟元素是 p 时，该 p 才会被选中 */
  color: red;
}
```

- 用于选中**某元素之后的第一个兄弟元素**，前提是其标签类型符合要求
- 两个元素必须属于**同一个父元素**（是同级兄弟关系）
- 常用于“标题 + 段落”、“按钮 + 提示”等结构清晰的内容块控制

---

## 3. 伪类选择器：结构型序选择器（`:first-child` 等）

- 伪类选择器：伪类选择器用于选中元素在特定状态或结构中的位置。
  - 结构型序选择器：结构性伪类又称**序选择器**，用于选中“父元素中第 N 个子元素”。

```css
div p:first-child {	/* 匹配所有位于 div 内部，且是其父元素第一个子元素的 p */
  color: red;
}
```

- 匹配所有位于 `div` 元素内部，且是**其各自父元素的第一个子元素**的 `<p>` 元素
- 推荐显式写出父元素选择器（如 `div`），提高语义清晰度和匹配精度

### 3.1 常见序选择器

| 选择器          | 含义                   |
| --------------- | ---------------------- |
| `:first-child`  | 父元素中第一个子元素   |
| `:last-child`   | 父元素中最后一个子元素 |
| `:nth-child(n)` | 父元素中第 n 个子元素  |
| `:only-child`   | 父元素中唯一的子元素   |

### 3.2 易混淆点

```html
<div>
  <p></p>
  <ul><li></li></ul>
</div>
```

```css
div ul:first-child {	/* ❌ 不会匹配上，因为 ul 不是 div 的第一个子元素，p 才是。 */
  color: red;
}
```

> ✅ 注意：`:first-child` 判断的是**元素在其父元素中的真实结构顺序**，而不是标签名或 class 出现的顺序。必须是父元素的**第一个子元素**才会被匹配。

---

## ✅ 总结

- 组合选择器用于描述元素间的结构关系或条件并列关系，是 CSS 样式系统的表达基础
- 常见结构组合：后代（空格）、子代（`>`）、相邻兄弟（`+`）
- 常见条件组合：交集（并列）、并集（`,`）
- 结构型伪类（如 `:first-child`）用于选中特定顺序位置的元素，需理解其严格的“结构判断”语义
- 掌握基本规则后，组合选择器可构建出复杂但清晰的样式匹配系统
