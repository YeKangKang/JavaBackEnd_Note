# Day15 · CSS进阶（类名冲突、!important机制、盒模型基础）

本章继续深入 CSS 层叠机制，补充类名冲突与 `!important` 的特殊规则，并引入盒模型的基本结构与核心属性行为。

---

## 1. 多类名冲突判断

HTML 元素可以同时携带多个类名，例如：

```html
<p class="spec1 spec2">文字</p>
```

若 `.spec1` 和 `.spec2` 都有对应的样式定义，则最终哪个样式生效，**与类名在标签中书写的先后顺序无关**，仅取决于以下两点：

- **选择器的权重值**：权重高者生效
- **权重相同时**：后声明的样式覆盖前面的

> 类名顺序不影响权重计算；CSS 只比较选择器的权重和声明顺序。

---

## 2. `!important` 插队机制

### 2.1 基本语法

```css
color: red !important;
```

- `!important` 只能用于样式属性值末尾，表示该属性在命中时**优先于未加 `!important` 的同类属性生效**
- 它仅作用于所修饰的属性，其他属性仍按正常权重判断
- 只有当选择器**成功命中元素**时，`!important` 才会生效
  - 若选择器未命中，则 `!important` 不会有效果


> `!important` 并不会“提升选择器本身的权重”，它只影响该属性在命中后的优先级。

### 2.2 示例

带有 `!important` 的属性可覆盖所有**未加 `!important` 的同属性声明**，即使对方同级或权重更高：

```css
p {
  color: red !important;
}
.text {
  color: blue;
}
```

如果 `<p class="text">` 同时被两个选择器命中，则最终颜色为红色。

> ❗ 滥用 `!important` 会降低样式可维护性，应谨慎使用，仅在必要时作为兜底手段。

## 3. 盒模型基础结构

CSS 中每个元素渲染为一个“盒子”，由以下 5 部分组成：

| 属性      | 说明                                         |
| --------- | -------------------------------------------- |
| `width`   | **内容区宽度**，不含 `padding` 与 `border`   |
| `height`  | **内容区高度**，不含 `padding` 与 `border`   |
| `padding` | **内边距**，内容与边框之间的间距（四个方向） |
| `border`  | **边框**，包裹在 `padding` 外部              |
| `margin`  | **外边距**，定义与其他元素之间的间距         |

> 默认下盒子的 `width` / `height` 只定义**内容区域尺寸**，实际占据空间为：
> `width/height + 左右/上下 padding + 左右/上下 border`

---

## 4. `padding` 属性详解

### 4.1 结构与渲染范围

- `padding` 定义**内容区**与**边框**之间的间距
- `background-color` 会统一作用于内容区和 `padding`，无法为二者分别设置颜色

> 💡 行内元素（如 `span`）的某些方向 `padding` 可能不生效。
>
> 💡 部分标签（如 `ul`、`h1`）浏览器自带默认的 `margin` 或 `padding`。实际开发中通常会通过初始化样式将其统一清除。

---

### 4.2 三种写法

#### ✅ 小属性写法（四个方向分别写）

```css
padding-top: 10px;
padding-right: 20px;
padding-bottom: 30px;
padding-left: 40px;
```

- 顺序不强制，推荐统一使用“上右下左”
- 未声明的方向默认为 `0`

#### ✅ 综合属性写法（推荐）

```css
/* 上右下左 */
padding: 10px 20px 30px 40px;

/* 上 | 左右 | 下 */
padding: 10px 20px 30px;

/* 上下 | 左右 */
padding: 10px 20px;

/* 全部相同 */
padding: 20px;
```

> 必须遵循顺序：上 → 右 → 下 → 左（顺时针）

#### ✅ 层叠写法（小属性覆盖综合属性）

先设置 4 个方向统一值，再单独修改某个方向：

```css
padding: 50px;
padding-left: 30px;
```

---

## ✅ 总结

- 多类名共存时，最终样式由**权重 + 声明顺序**共同决定，类名顺序无影响
- `!important` 用于提升单个属性的优先级，仅在选择器命中元素时生效
- `width` / `height` 定义的是内容区尺寸，实际占位还需加上 `padding` 与 `border`
- `padding` 支持多种写法，综合属性必须遵循“上右下左”顺序，小属性无顺序要求
