# Day15 · CSS进阶（继承性、层叠性、权重机制）

本章介绍 CSS 的继承性、层叠性与权重计算机制。重点掌握“哪些属性可以继承”、“多个规则冲突时谁优先生效”以及“四段式权重计算规则”的实际应用。

---

## 1. 继承性

CSS 中部分属性支持被嵌套子元素自动继承，常用于统一定义文本样式，减少重复声明。一般而言，**与文本内容或排版相关的属性**可继承，如 `color`、`font-size`，而**与布局、盒模型相关的属性**不可继承，如 `margin`、`display` 等。

### 1.1 可继承属性

可继承的多为**文本相关属性**，例如：

- `color`：文本颜色
- `font-` 系列属性：字体、字号、粗细、风格等
- `text-` 系列属性：对齐、缩进、装饰线、转换等
- `line-` 系列属性：行高、文本裁剪等

> 部分表格类属性、列表属性、书写方向属性也支持继承。

### 1.2 不可继承属性

布局、定位、尺寸、盒模型等**结构相关属性**不会继承：

- 盒模型尺寸类：`margin`, `padding`, `width`, `height`
- 布局与定位类：`position`, `display`, `border`, `flex` 等

---

## 2. 层叠性与权重机制（Cascade & Specificity）

当多个样式规则作用于同一元素时，CSS 会根据一套层叠规则（Cascade）决定最终使用哪个样式。

---

### 2.1 样式冲突判断流程

- 若**未命中同一元素**：按“就近原则”，结构上更靠近的样式优先；若多个样式结构位置相同，再进行权重比较。
- 若**命中同一元素**：执行权重比较（见下节）

---

### 2.2 权重机制与计算规则

当多个样式命中同一元素时，CSS 使用四段式权重 `(a, b, c, d)` 比较优先级，逐位从左向右判断大小。**当权重相同时，后声明的规则将覆盖前声明的样式**。

| 位次 | 含义                     | 示例                                    |
| ---- | ------------------------ | --------------------------------------- |
| a    | 行内样式                 | `<div style="color:red">` → `a=1`       |
| b    | ID 选择器数量            | `#app` → `b=1`                          |
| c    | 类、伪类、属性选择器数量 | `.box`, `:hover`, `[type=text]` → `c+1` |
| d    | 标签、伪元素选择器数量   | `div`, `p`, `::before` → `d+1`          |

> 即使 `d=100`，也比不过 `c=1`，高位优先级绝对大于低位。
>
> 并集选择器（`,`）中的每个子选择器**独立计算权重**，不会互相影响。

---

### 2.3 权重示例解析

以下为常见选择器的权重计算示例：

| 选择器                    | 权重值  | 说明                          |
| ------------------------- | ------- | ----------------------------- |
| `div p:first-child`       | 0-0-1-2 | 2 标签 + 1 伪类               |
| `h1 + p`                  | 0-0-0-2 | 2 标签                        |
| `#main div p:first-child` | 0-1-1-2 | 1 ID + 1 伪类 + 2 标签        |
| 行内样式                  | 1-0-0-0 | `<div style="...">`，权重最高 |

---

## ✅ 总结

- CSS 支持继承性：文字相关属性默认继承，布局类属性不继承
- 多规则冲突时，若命中同一元素则比较权重，未命中则不参与
- 权重采用 `(a, b, c, d)` 四元组结构，依次比较
- 并集选择器每项权重独立；最终权重相同时，以最后声明的为准
