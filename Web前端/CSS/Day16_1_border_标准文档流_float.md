# Day16 · CSS进阶（盒模型续、标准文档流、float浮动）

本章介绍盒模型中 `border` 的声明方式与行为，标准文档流对元素排布的影响，以及经典的 `float` 浮动布局机制。重点掌握边框声明结构、块级/行内元素差异，以及浮动带来的排版特性。

---

## 1. Border 边框属性

### 1.1 概念

`border` 是盒模型结构中的核心属性之一，具有如下特性：

- `border` 位于 `padding`（内边距）与 `margin`（外边距）之间，是盒子的边框
- 由三个要素组成：**粗细 `width`、线型 `style`、颜色 `color`**

> 无论使用哪种方式声明 `border`，都必须显式指定 `border-style`，否则边框不会被渲染。

---

### 1.2 声明方式

#### ✅ 统一声明（常用）

```css
border: 10px solid red;
```

- 顺序：`宽度` `线型` `颜色`
- 推荐用于快速统一设置所有方向

#### ✅ 三要素分离声明

```css
border-width: 10px;
border-style: dotted;
border-color: red;
```

- 本质等价于统一声明，只是分别书写

#### ✅ 按方向声明

```css
border-top: 10px solid red;
border-right: 10px dotted red;
border-bottom: 10px dashed red;
border-left: 10px solid red;
```

- 分别为四条边设置不同样式

#### ✅ 最细化声明

```css
border-top-style: solid;
border-left-color: blue;
```

- 使用 `border-[方向]-[子属性]` 格式单独指定细节
- 子属性包括：`style`, `width`, `color`

#### ✅ 层叠覆盖写法（常用）

可通过统一声明设置初始样式，再局部覆盖特定方向：

```css
border: 30px solid red;
border-right-style: dotted;
```

> 隐藏边框可通过设置 `border: none` 或将 `border-width` 设为 `0` 实现，两种方式等效。

---

## 2. 标准文档流（Normal Flow）

### 2.1 概念

标准文档流是浏览器默认的元素排列机制。元素不受特殊样式干扰时，会依 HTML 结构自上而下自然排列，依据元素类型（**块级元素** / **行内元素**）自动布局。

> 常见现象如“空白折叠”、“自动换行”、“图片底边对齐”都来源于标准文档流。

### 2.1 块级元素（block）

块级元素常用于结构布局与容器封装，如 `div`、`p`、`ul`、`h1`～`h6` 等。其主要特性包括：

- 独占一整行，不与其他元素并排
- 支持设置 `width` 与 `height`
- 未设置宽度时，默认占满父容器的可用宽度

### 2.2 行内元素（inline）

行内元素常用于文本修饰或小范围语义标记，常见标签包括 `<span>`、`<a>`、`<img>`、`<strong>` 等。其特性如下：

- 与其他元素可并排显示，不会独占整行
- 不支持设置 `width` 和 `height`，尺寸由内容自动撑开

---

### 2.3 元素特性转换：`display`

元素通过 `display` 属性可改变其默认布局特性，但不会破坏 HTML 语义：

- 块 → 行内：`display: inline;`
- 行内 → 块：`display: block;`

> 推荐使用 `display` 而非修改标签类型，以保留语义一致性

---

## 3. 浮动布局（float）

### 3.1 背景

标准文档流限制了元素的排列方式，若希望实现“既可设置尺寸、又能并排”的布局需求，必须使用脱离标准流的机制，`float` 是早期主流方案。

> 现已被 `flex` / `grid` 等现代布局替代，但仍需理解其历史与行为。

---

### 3.2 `float` 基本特性

```css
float: left;   /* 左浮动 */
float: right;  /* 右浮动 */
```

- 元素将脱离标准流，允许与其他元素并排显示
- 浮动元素具有**块级与行内的双重特性**
  - 如 `div` 可多个并排、`span` 可设置宽高
- 可能引发与标准流元素的遮挡问题

> 标准流文本内容不会被浮动元素遮挡，而是会自动环绕它排列

---

### 3.3 浮动元素之间的排列规则

以 `float: left` 为例：

- 多个元素会依次向左排列，尽可能贴紧左边及前一个元素
- 若横向空间不足，尝试换行并寻找下一个可贴紧点（称为“**矩形贴边尝试**”）

---

## ✅ 总结

- `border` 可用四种方式声明，统一声明+局部覆盖是常用方式
- 标准文档流按元素类型自然排布，决定默认布局
- `block` 独占一行、可设置尺寸；`inline` 并排排列，不可设宽高
- 可通过 `display` 切换元素布局特性，避免破坏语义
- `float` 可让元素脱离标准流并并排排列，但会产生重叠与包围现象
