# Day14 · CSS基础（简介、基础选择器）

本章介绍 CSS 的基本语法结构、常见样式属性及四类基础选择器。重点理解“选择器选谁”和“样式如何层叠”的机制。

---

## 1. CSS 简介与前端三大核心

回顾一下前端开发的三大组成部分：

| 技术 | 作用 |
|------|------|
| HTML | 从语义角度描述页面结构（内容是什么） |
| CSS  | 从审美角度负责页面样式（外观怎么展示） |
| JS   | 从交互角度描述页面行为（能做什么） |

### 什么是CSS？ 

CSS（Cascading Style Sheets，层叠样式表）是一种控制网页样式和布局的语言。

> 当多个样式规则作用于同一元素时，CSS 会根据**优先级规则**决定最终使用哪个样式，这就是“层叠”的含义。

---

## 2. CSS 语法规范

```css
选择器 {
  属性名1: 属性值1;
  属性名2: 属性值2;
}
```

- 每条样式规则由 **选择器 + 属性集合** 构成
- 属性以 `键:值;` 形式书写，分号结尾
- **空格和换行不敏感**，以分号分隔为准

### 2.1 内嵌样式表（Internal CSS）
将样式写在 HTML 文件的 `<head>` 区域，通过 `<style>` 标签引入：

```html
<style type="text/css">
  p {
    color: red;
  }
</style>
```

### 2.2 外部样式表（External CSS）
将样式写在 `.css` 文件中，使用 `<link>` 标签引入：

```html
<link rel="stylesheet" href="style.css">
```

## 3. 常见 CSS 属性示例

| 属性               | 说明                       | 示例                      |
|--------------------|----------------------------|---------------------------|
| `color`            | 文本颜色      | `color: red;`             |
| `font-size`        | 字体大小（需单位）         | `font-size: 16px;`        |
| `font-weight`      | 字体粗细                   | `font-weight: bold;`      |
| `font-style`       | 字体风格                   | `font-style: italic;`     |
| `font-family`      | 字体系列                   | `font-family: Arial;`     |
| `text-decoration`  | 文本修饰（如下划线等）      | `text-decoration: underline;` |
| `background-color` | 背景颜色 | `background-color: #f0f0f0;` |

## 4. CSS 基础选择器

基础选择器用于精确选中 HTML 元素。共分为 4 类：

### 4.1 元素选择器

选中所有某种类型的标签。

```css
h1 {
  color: red;	/* 将所有 <h1> 元素的字体颜色设置为红色 */
}
```

---

### 4.2 ID 选择器（`#`）

使用 `#` 符号选中具有特定 `id` 的元素。

```css
#car {
  color: red;	/* 选中 id="car" 的元素并设置为红色 */
}
```

#### ID 注意事项

- 一个页面中 `id` 应该唯一
- `id` 名称必须以字母开头，只能包含字母、数字和下划线
- 不建议与标签名重名（虽合法，但可读性差）

---

### 4.3 类选择器（`.`）

使用 `.` 符号选中具有指定 `class` 的所有元素。

```css
.foodtext {
  color: red;	/* 所有 class 为 foodtext 的元素字体变红 */
}
```

> 与 `id` 不同，`class` 名可以在多个元素中重复使用。

---

### 4.4 通配符选择器（`*`）

选中**页面中所有元素**，常用于样式初始化。

```css
* {	/* 初始化设置，清除所有标签的默认外边距与内边距 */
  margin: 0;
  padding: 0;
}
```

> 通配符选择器也可以与其他选择器组合使用（如 `div *`），但实际开发中需注意性能影响。

---

## ✅ 总结

- CSS 是控制网页样式的语言，具有层叠（冲突解决）机制
- 样式以 `选择器 { 属性: 值; }` 的格式书写，分号结尾，换行不敏感
- 常用属性包括颜色、字体、背景、文本修饰等
- 四类基础选择器：元素选择器、ID选择器、类选择器、通配符选择器，是后续样式控制的基础工具
