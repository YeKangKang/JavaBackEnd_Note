
# Day17 · CSS3 新特性（属性选择器、结构型伪类选择器、伪元素选择器、transform属性样式）

---

## 1. 属性选择器

属性选择器用于根据 HTML 元素的属性或属性值选中元素，比类名、ID 更精细，并可参与组合选择器构成更强大的匹配条件。

### 基本语法

```css
[attribute operator value]
```

> 其中 [] 内部表达式本身可单独构成选择器，也常用作复合选择器的一部分，如：`div[type="text"]`

### 常见形式

| 语法            | 说明                                                         |
| --------------- | ------------------------------------------------------------ |
| `[attr]`        | 选中含有指定属性的元素                                       |
| `[attr="val"]`  | 属性值等于 `val`                                             |
| `[attr~="val"]` | 属性值中含有以**空格分隔的一组值**，其中某个值恰好等于 `val` |
| `[attr^="val"]` | 属性值以 `val` 开头（前缀匹配）                              |
| `[attr$="val"]` | 属性值以 `val` 结尾（后缀匹配）                              |
| `[attr*="val"]` | 属性值中包含 `val`（子串匹配，不限位置）                     |

## 2. 结构型伪类选择器（序选择器）

根据元素在父容器中的“结构位置”来选中目标，常用于 DOM 结构控制下的精确样式定位。

### 常用伪类

| 选择器             | 含义说明                       |
|--------------------|--------------------------------|
| `:first-child`     | 是父元素的第一个子元素         |
| `:last-child`      | 是父元素的最后一个子元素       |
| `:nth-child(n)`    | 是父元素的第 n 个子元素        |
| `:nth-last-child(n)` | 是父元素的倒数第 n 个子元素 |
| `:only-child`      | 是父元素中唯一的子元素         |
| `:first-of-type`   | 是该标签类型在父元素中的第一个 |
| `:last-of-type`    | 是该标签类型在父元素中的最后一个 |
| `:nth-of-type(n)`  | 是该类型标签在父元素中的第 n 个 |
| `:only-of-type`    | 是父元素中唯一的该类型元素     |
| `:empty`           | 无任何子节点（文本、空格、注释） |

> `last-child` vs `last-of-type` 的区别：前者是“所有子元素中最后一个”，后者是“同类元素中的最后一个”。后者更易命中。

### `:nth-child(n)` 说明

- **具体数字**：如 `:nth-child(3)`
- **关键字**：`odd`（奇数），`even`（偶数）
- **数学表达式**（n 从 0 开始）：  
  - `2n`：偶数位  
  - `2n+1`：奇数位  
  - `5n`：每 5 个匹配一次  
  - `n+5`：从第 5 个开始  
  - `-n+5`：前 5 个匹配

## 3. 伪元素选择器

伪元素用于选中元素的某个“逻辑区域”或插入视觉性内容，不影响 DOM 结构，是视觉层级上的增强。

### 插入型伪元素

插入型伪元素用于在元素内容边界**插入视觉内容**，这些内容不会出现在 DOM 结构中，仅作为渲染结果存在于页面中。

| 伪元素        | 功能说明                               |
|---------------|----------------------------------------|
| `::before`    | 在元素内部内容前插入虚拟内容           |
| `::after`     | 在元素内容后插入虚拟内容               |

> 插入型伪元素 `::before` 和 `::after` 会分别插入到元素内容的最前面与最后面，必须通过 `content` 指定插入内容才会生效。

### 区域型伪元素

区域型伪元素用于选中目标**元素中某个特定的虚拟显示区域**，以实现局部样式定制。

| 伪元素           | 功能说明                             |
|------------------|--------------------------------------|
| `::first-line`   | 选中文本的第一行                     |
| `::first-letter` | 选中首行的第一个字符                 |
| `::selection`    | 用户选中的文本区域                   |
| `::placeholder`  | 表单控件中的 placeholder 提示文字    |

## 4. 2D 转换与 `transform` 属性

`transform` 是 CSS3 提供的视觉变换属性，用于实现平移、旋转、缩放、倾斜等二维变换效果，**不会影响元素在文档中的布局，仅在视觉上呈现变化**。

常见函数包括：`translate()` 平移，`scale()` 缩放，`rotate()` 旋转，`skew()` 倾斜。

> `transform` 不影响文档流，而 `float` 属于布局属性，会改变页面结构。

---

### 4.1 `translate()` 平移

用于在视觉上将元素水平、垂直方向平移。

- `translate(x, y)`：x 表示水平偏移，y 表示垂直偏移
- `translateX(n)`：仅沿 x 轴平移
- `translateY(n)`：仅沿 y 轴平移

支持单位：`px`、`em`、`%`（相对自身尺寸）

> 行内元素默认不支持 `transform`，需设为 `inline-block`

---

### 4.2 `rotate()` 旋转

用于围绕元素中心点进行旋转，顺时针为正角度，逆时针为负角度。

- `rotate(45deg)`：顺时针旋转 45°
- `rotate(-90deg)`：逆时针旋转 90°

支持单位：`deg` 角度制（常用）、`rad` 弧度制等。

> 默认旋转中心为元素中心，可使用 `transform-origin` 修改旋转基点

---

## ✅ 总结

- 属性选择器增强了选择器的精度，常用于组件级样式控制
- 结构性伪类用于按 DOM 位置选中目标，适合动态内容控制
- 伪元素实现视觉插入或局部美化，不影响结构
- `transform` 提供平移旋转等动效能力，现代动效核心
