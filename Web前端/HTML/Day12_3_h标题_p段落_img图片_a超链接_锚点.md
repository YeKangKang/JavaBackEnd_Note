# Day12 · Web基础（h标题、p段落、img图片、a超链接与锚点）

本节介绍 HTML 中常见结构性标签：标题（`h1~h6`）、段落（`p`）、图像嵌入（`img`）、超链接（`a`）及锚点跳转等内容，重点理解标签语义、嵌套规范与常用属性，为后续布局与交互设计奠定基础。

---

## 1. 标题标签 `<h1>`~`<h6>`

### 1.1 语义与结构

- `h` 是 heading 的缩写，表示标题。
- 标题标签从 `<h1>` 到 `<h6>`，级别逐级递减。
- 属于块级元素，不能嵌套其他块级元素。

示例：

```html
<h1>常见的编程语言</h1>
<h2>Java</h2>
<h3>流程控制</h3>
<h3>数组遍历</h3>
<h2>C++</h2>
<h3>流程控制</h3>
```

> 注意：**标题标签 `<h1>`–`<h6>` 之间不允许嵌套**，应通过标签顺序表示层级结构。

---

## 2. 段落标签 `<p>`

### 2.1 基本特性

- `p` 是 paragraph 的缩写，表示段落内容。
- 块级元素，不能嵌套其他块级元素，只能包含**内联元素**（如文字、`img`、表单控件等）。

示例：

```html
<p>这是一个段落文字。</p>
<p><img src="image.png" alt="图片"></p>
<p>
  <input type="password" />
  <br />
  <input type="button" value="提交密码" />
</p>
```

## 3. 图片标签 `<img>`

### 3.1 基本语法

- `<img>` 是**自封闭标签**（空元素），用于嵌入图片。
- 属于内联元素，可嵌套于段落、超链接等标签中。

常见属性：

| 属性名 | 说明 |
|--------|------|
| `src`  | 图片路径，推荐使用相对路径 |
| `alt`  | 替代文本，图片无法显示时展示 |

示例：

```html
<img src="images/flower.png" alt="一朵花的图片" />
```

### 3.2 支持的图片格式

- ✅ 支持：`.jpg` / `.jpeg`、`.gif`、`.png`、`.bmp`
- ❌ 不支持：`.psd`（Photoshop 源文件）、`.ai`（矢量图源文件）

### 3.3 路径书写示例

```html
<img src="images/img.png" />             <!-- 同级目录中的子文件夹 -->
<img src="img.png" />                   <!-- 当前文件夹 -->
<img src="../img.png" />                <!-- 上一级文件夹 -->
<img src="../../img.png" />             <!-- 上两级目录 -->
<img src="../images/img.png" />         <!-- 上一级文件夹中的子目录 -->
```

## 4. 超链接标签 `<a>`

### 4.1 基本用法

- `a` 是 anchor（锚）的缩写，用于创建超链接。
- 为**内联元素**，通常包裹文字或图像，点击后跳转。

```html
<a href="1.html">点击跳转到页面</a>
```

### 4.2 常用属性

| 属性名   | 说明 |
|----------|------|
| `href`   | 指定跳转目标地址（建议使用相对路径） |
| `title`  | 悬停时提示文本（**全局属性**） |
| `target` | 打开位置，`_blank` 表示新窗口打开 |

示例：

```html
<a href="1.html" title="前往页面" target="_blank">跳转链接</a>
```

---

## 5. 页面锚点（跳转页面内指定位置）

### 5.1 实现原理

- 通过设置 `id` 属性为页面内任意元素创建锚点。
- 使用 `<a href="#id值">` 可跳转到该锚点。

### 5.2 锚点用法

```html
<!-- 锚点定义 -->
<h2 id="section1">HTML 段落</h2>

<!-- 页面内跳转 -->
<a href="#section1">跳转到段落部分</a>

<!-- 跳转到其他页面指定位置 -->
<a href="other.html#target">跳转到其他页面的锚点</a>
```

> `id` 为全局属性，页面内应保持唯一。

---

## 6. 图片超链接（图可点击跳转）

可将 `<img>` 标签嵌套在 `<a>` 标签中实现图片点击跳转功能：

```html
<a href="1.html#idname" target="_blank">
  <img src="../imagesFile/img.png" alt="图片超链接" />
</a>
```

---

## ✅ 总结

- `h`、`p` 是结构性块级标签，注意嵌套规则。
- `img` 为内联空元素，必须使用 `src` 与 `alt` 属性。
- `a` 可包裹文本或图片实现跳转，支持页面内锚点跳转。
- 相对路径 `../` 表示访问上一级目录，可叠加多级。
