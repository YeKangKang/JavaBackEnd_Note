本章介绍 HTML 表单结构与常见控件（文本框、密码框、单/多选按钮、下拉列表、文本域、按钮等），并补充字符实体等 HTML 杂项内容。

## 1. 表单结构 `<form>`

HTML 表单用于收集用户输入。语法格式：

```html
<form action="/login" method="post"> ... </form>
```

- `action`：表单数据的提交地址，一般为后端接口路径
- `method`：提交方式，仅支持 `GET` 和 `POST`

#### GET vs POST

| 方法 | 数据位置 | 安全性 | 用途 |
|------|-----------|--------|------|
| GET | URL 中拼接参数 | ❌ 不安全 | 查询、搜索、跳转 |
| POST | 请求体中提交参数 | ✅ 安全 | 提交登录、注册、表单等 |

> 表单提交时，浏览器会打包该 `<form>` 中所有具有 `name` 属性且未被禁用的字段，以 `name=value` 的格式提交到 `action` 属性指定的路由地址。

## 2. 输入控件 `<input>`

### 2.1 通用属性

```html
<input type="类型" name="字段名" value="默认值/提交值">
```

- `type`：控件类型（如 `text`、`password`、`radio` 等）
- `name`：字段名，必须有才能提交
- `value`：默认值或当前值

### 2.2 `type` 常见类型

| 类型 | 用法说明 |
|------|-----------|
| `text`（默认） | 单行文本框 |
| `password` | 密码框，隐藏输入内容 |
| `radio` | 单选按钮，`name` 相同的互斥 |
| `checkbox` | 复选按钮，`name` 相同的可多选 |
| `submit` | 提交按钮，发送当前表单所有字段到 `action` 指定地址 |
| `reset` | 重置按钮，恢复表单中所有控件的初始值 |
| `button` | 普通按钮，无行为，需配合 JS |

> `input` 是内联元素，自闭合，不能嵌套内容。

> 🚫 按钮类控件（`submit/reset/button`）本身不用于提交值，除非显式指定 `name` 并作为用户点击的提交源，此类情况一般仅在复杂交互中使用。

## 3. 下拉列表 `<select>`

支持从选项中选择一项（默认）或多项（添加 `multiple` 布尔属性）：

```html
<select name="city">
  <option value="beijing" selected>北京</option>	<!-- selected 关键字表示默认选中的值 -->
  <!-- optgroup 是结构标签，必须通过 label 属性定义组名，不能写文字在标签体中 -->
  <optgroup label="江苏省">
    <option value="1">南京</option>
    <option value="2">苏州</option>
  </optgroup>
</select>
```

#### 子元素说明

| 标签 | 说明 |
|------|------|
| `<option>` | 内联元素，表示单个选项，只允许纯文本 |
| `<optgroup>` | 分组选项容器，必须通过 `label` 属性设置分组标题，仅允许嵌套 `<option>` 元素 |

> `<select>` 默认提交选中 `<option>` 的 `value` 值，字段名来自 `<select name="...">`。

## 4. 多行文本框 `<textarea>`

用于输入多行文本内容：

```html
<textarea name="comment" rows="4" cols="40">默认值</textarea>
```

- 默认值写在标签体内，而非 `value` 属性
- 支持换行、滚动、限制长度等功能
- 只能嵌套纯文本，不能含标签内容

---

## 5. 标签说明 `<label>`

`<label>` 是表单中的说明性标签，常与输入控件配合使用，用于标注字段含义，并通过绑定实现点击聚焦，提高表单的可用性与可访问性。

### 5.1 显式绑定（推荐）

```html
<label for="username">用户名：</label>
<input type="text" id="username">
```

### 5.2 隐式绑定

```html
<label>
  用户名：
  <input type="text" name="username">
</label>
```

> 一个 `<label>` 最多关联一个控件，可嵌套 `span`、`div` 等结构，但不推荐嵌套多个控件。

### 7.2 常见字符实体

| 实体 | 显示字符 | 名称说明 |
|------|------------|-----------|
| `&lt;` | `<` | less than（小于号） |
| `&gt;` | `>` | greater than（大于号） |
| `&amp;` | `&` | ampersand（与号） |
| `&quot;` | `"` | quotation mark（双引号） |
| `&apos;` | `'` | apostrophe（单引号，HTML5 支持） |
| `&nbsp;` |   | 不间断空格 |
| `&copy;` | © | copyright（版权符号） |

> ✅ 连续空格请使用多个 `&nbsp;` 实现，避免被 HTML 折叠规则合并。

## ✅ 总结

- 表单是数据提交的基础结构，通过 `action` 与 `method` 控制数据流向与方式。
- `input`、`select`、`textarea` 是表单三大输入控件，需合理设置 `type`、`name`、`value`。
- `<label>` 用于绑定控件说明，可提升用户体验与可访问性。
- 提交行为遵循“所属 `<form>`、带 `name`、非 disabled”原则。
- 字符实体用于在页面中安全地表示特殊字符，如 `<`、`&`、空格等。
