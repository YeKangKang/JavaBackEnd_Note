# Day13 · Web基础（列表、div标签、span标签）

本章介绍 HTML 中三类列表（有序`ol`、无序`ul`、定义`dl`）的结构与语义区别，以及结构性容器标签 `div` 与内联容器 `span` 的使用场景，是构建网页结构的重要基础。

---

## 1. 列表标签（`<ul>`、`<ol>`、`<dl>`）

HTML 中共有三种列表类型：

- **无序列表**（`<ul><li>`）：用于表达“无序的内容项”。
- **有序列表**（`<ol><li>`）：用于表达“有顺序的内容项”。
- **定义列表**（`<dl><dt><dd>`）：用于表达“术语-定义”关系。

> ✅ 所有列表标签本身都是块级元素，拥有完整的结构语义。

### 1.1 无序列表 `<ul><li>`

- `<ul>`：Unordered List，无序列表容器，仅可直接嵌套 `<li>`。
- `<li>`：List Item，列表项容器。可嵌套内联与块级元素，但不能嵌套另一个 `<li>`。

示例结构：

```html
<ul>
  <li>红楼梦</li>
  <li><a href="www.google.com" target="_blank">打开谷歌</a></li>
  <li>
    <div>
      <ul>
        <li>第一个选项</li>
        <li>第二个选项</li>
      </ul>
    </div>
  </li>
</ul>
```

### 1.2 有序列表 `<ol><li>`

与无序列表结构一致，区别仅在于语义和浏览器默认样式：

- `<ol>`：Ordered List，有序列表容器。
- `<li>`：列表项容器，支持内容与嵌套结构同 `<ul>`。

```html
<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>
```

> ✅ 开发中 `<ul>` 使用频率更高，但语义明确时应优先选择合适类型。

### 1.3 定义列表 `<dl><dt><dd>`

专用于表示“术语-描述”结构，更强调语义性：

- `<dl>`：Definition List，定义列表容器。
- `<dt>`：Definition Term，术语项。
- `<dd>`：Definition Description，描述内容。

所有标签均为块级元素，`<dt>` 与 `<dd>` 可自由嵌套内容（除彼此自身）。

```html
<dl>
  <dt>北京</dt>
  <dd>中国首都</dd>
  <dt>深圳</dt>
  <dd>一线城市</dd>
</dl>
```

> ✅ 若语义偏向术语-说明的结构（如 FAQ），建议使用 `<dl>` 提升可读性和结构表达力。

---

## 2. 容器标签 div 与 span

`div` 与 `span` 是 HTML 中最常用的无语义容器，常用于结构布局与样式挂载。

### 2.1 div：块级容器

- `div` 是 division（分区）缩写，语义中性。
- 是**块级结构性容器**，可包裹任意元素（包括自身），常用于分块、布局、模块化。

```html
<div>
  <h2>模块标题</h2>
  <p>段落文字</p>
</div>
```

> ✅ 在 CSS 中用于设置区块样式、排版、定位等，是网页结构的主力框架。

### 2.2 span：内联容器

- `span` 是 **inline 范围容器**，语义中性。
- 是内联元素，用于包裹文字、图片、表单等文本级元素。
- 不能包裹块级元素，适合用于小范围局部样式控制或事件绑定。

```html
<p>请点击 <span class="highlight">这里</span> 查看详情</p>
```

> ✅ 用于微粒度样式控制，与 `div` 分工协作构成完整页面结构。

---

## ✅ 总结

- 列表标签（`ul`/`ol`/`dl`）各有明确语义，开发中应根据结构与含义选择。
- `li`/`dt`/`dd` 都是块级容器，可嵌套大部分结构内容，需注意语义合理性。
- `div` 是块级容器（大盒子），`span` 是内联容器（小盒子），共同用于结构组织与样式挂载。
