# Day12 · Web基础（HTML 入门与结构概述）

本节课是 HTML 学习的引入章节，主要帮助理解网页本质、浏览器行为与 HTML 文件的角色结构。

---

## 1. 浏览网页的本质

- 上网实质是**请求数据 + 接收文件**的过程
- Chrome 浏览器在访问网页时，会在本地**缓存网页相关资源文件**（可通过 `chrome://version/` → 个人资料路径观察临时目录）
- 再次访问同一网页时，因部分资源已存在本地，加载速度会更快（利用缓存）

### 浏览器的职责
- 加载网页文件（HTML / CSS / JS / 图片等）
- 解析内容结构与样式
- 渲染为用户可见的页面

---

## 2. 网页与服务器之间的关系

| 层面   | 说明                                                         |
|--------|--------------------------------------------------------------|
| 硬件   | 实际运行网页服务的计算机，配置强，长时间在线不关机         |
| 软件   | 提供服务响应的程序（即“后端”），处理请求与数据             |

- 网页资源由服务器保存，浏览器通过 HTTP 请求获取
- 后端程序常用语言有 Java、Python、C#，也可以用 Node.js（JavaScript）

---

## 3. HTTP 协议

- **HTTP（HyperText Transfer Protocol）** 是网页通信的基础协议
- 浏览器请求网页资源、服务器返回页面数据，都基于 HTTP 协议格式进行
- 后续还将涉及 HTTPS（安全协议）、状态码、请求头等内容

---

## 4. 网址结构解析

示例：`http://www.google.com/aaa/1.html`

| 部分                | 说明                             |
|---------------------|----------------------------------|
| `http`              | 所用协议                         |
| `www.google.com`    | 服务器域名，相当于 IP            |
| `aaa/1.html`        | 服务器内文件路径                 |

- 若省略路径，则默认访问 `index.html`
- 一个网页常由多个物理文件组成（HTML、CSS、JS、图片等）

---

## 5. 什么是 HTML

- HTML：超文本标记语言（Hyper Text Markup Language）
- 本质是**纯文本文件**，使用标签对标记结构与语义
- 文件扩展名通常为 `.html`，可用任何文本编辑器编写

### HTML 的特点

- 不属于编程语言，无逻辑控制结构
- 标签用于表达结构与语义（如标题、段落、列表等）
- 浏览器可识别并按语义渲染页面

### 示例标签语义

| 标签       | 语义说明       |
|------------|----------------|
| `<h1>`     | 主标题         |
| `<h2>`     | 二级标题       |
| `<p>`      | 段落           |

> **HTML 负责“语义”**，不负责“样式”或“行为”

---

## 6. HTML 的三层分离

| 组成层 | 作用说明                   | 对应技术  |
|--------|----------------------------|-----------|
| 结构层 | 内容结构、语义划分         | HTML      |
| 表现层 | 样式美化、字体颜色布局等   | CSS       |
| 行为层 | 动态交互、响应用户操作     | JavaScript|

- 虽然 HTML 标签也能写样式，但不推荐
- 合理分离有助于网页的可维护性与可拓展性

---

## 7. HTML 文件骨架结构

HTML 文件通常由三大块组成：`<!DOCTYPE>`、`<html>`、`<head>`、`<body>`

### 示例

```html
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en">
  <head>
    <meta http-equiv="Content-Type" content="text/html;charset=UTF-8">
    <title>网页标题</title>
  </head>
  <body>
    <!-- 页面可见内容 -->
  </body>
</html>
```

### 各部分含义

| 标签/部分    | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| `<!DOCTYPE>` | 文档类型定义，声明当前 HTML 使用的标准版本                   |
| `<html>`     | HTML 根标签，包含所有网页内容，常用属性包括 `xmlns`（命名空间）和 `lang`（页面语言） |
| `<head>`     | 页面配置区：字符集、标题、资源引用等                         |
| `<body>`     | 页面可见部分，展示用户能看到的结构和内容                     |
