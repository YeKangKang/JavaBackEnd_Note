# Day28 · Maven（概述、POM、仓库、坐标、settings.xml）

## 1. Maven 概述

Maven 是一个 Java 项目管理工具，基于 POM (项目对象模型) 的思想，提供统一的项目结构、依赖管理和构建流程。

- **依赖管理**：自动解析、下载和管理 jar 包，避免版本冲突
- **项目构建**：基于生命周期进行编译、打包、清理、部署
- **结构统一**：标准化的模块化结构

### Maven 核心组成

| 组成                | 说明                                             |
| ------------------- | ------------------------------------------------ |
| **`pom.xml`**       | 项目核心配置文件                                 |
| **生命周期 / 阶段** | Maven 构建的预定义流程                           |
| **依赖管理**        | 自动解析和管理依赖的资源                         |
| **仓库**            | 依赖资源存放地                                   |
| **插件**            | 包含操作目标的功能集合，用于编译、打包等构建任务 |

---

## 3. POM 常用标签（项目对象模型）

`pom.xml` 是 Maven 项目的核心配置文件，定义了项目的依赖、构建方式、插件使用等，其常用标签为：

- **坐标**：`groupId`、`artifactId`、`version`
- **依赖列表**：`dependencies`
- **构建、插件列表**：`build`、`plugins`
- **模块结构**：`modules`（多模块项目）
- **仓库地址**：`repositories`（用于定位依赖来源）
- **继承、属性**：`parent`、`properties`

> POM 可视为 Maven 的“说明书”，告诉它该怎么构建项目、用什么工具、去哪里找资源。

---

## 4. 仓库（Repository）

Maven 仓库用于存放构建所需的依赖资源，分为本地仓库和远程仓库。

### 仓库类型

| 类型         | 说明                                      |
| ------------ | ----------------------------------------- |
| **本地仓库** | 存放下载的依赖，默认在 `~/.m2/repository` |
| **中央仓库** | Maven 官方公共仓库，包含大量开源组件      |
| **私有仓库** | 企业部署用于内部共享或加速载入            |

> **依赖解析顺序**：本地仓库 → 配置的私有仓库 → 中央仓库

---

## 5. 坐标 (Coordinates)

Maven 坐标是用来唯一标识一个构件或项目的运行信息，根据坐标可以在本地和远程仓库中精确定依赖位置。

```xml
<project>
  <groupId>org.mybatis</groupId>         <!-- 项目所属组织（通常是域名反写） -->
  <artifactId>mybatis</artifactId>       <!-- 模块名，唯一标识名称 -->
  <version>3.5.10</version>              <!-- 版本号 -->
</project>
```

> Maven 坐标（`groupId:artifactId:version`）唯一标识每个构件，并**按坐标生成路径，在仓库中精确定位目标资源**。

## 6. settings.xml 配置

Maven 支持两类配置：**全局配置** `Maven目录下` + **用户配置** `~/.m2/ 目录`，其中用户配置优先级高。

Maven 不推荐直接修改全局 settings.xml，而是备份后放到 `.m2` 中进行用户级配置。

### 6.1 修改本地仓库路径

```xml
<settings>
  <localRepository>绝对路径</localRepository>
</settings>
```

### 6.2 配置镜像仓库

```xml
<mirrors>
  <mirror>
    <id>镜像标识符（自定义命名，需在 mirrors 中唯一）</id>
    <mirrorOf>指定要替换的仓库，一般为 central</mirrorOf>
    <name>镜像名称（描述用，无实际作用）</name>
    <url>镜像地址（通常为 CDN 加速后的仓库）</url>
  </mirror>
</mirrors>
```

> - 镜像仓库本质上是用于替代默认远程仓库，用于控制网速或优化资源下载
>
> - Maven 配置是“合并 + 覆盖”机制，用户配置只会覆盖重名项，其余项目保留不变

---

## ✅ 总结

- Maven 是构建和依赖管理工具，根据 POM 核心配置项目
- 通过生命周期 + 插件 + 坐标精确控制构建过程
- 依赖解析由仓库支持，包括本地仓库、镜像仓库和私有仓库
- `settings.xml` 用于配置本地仓库路径和镜像，用户配置优先于全局
- Maven 建议统一由 Maven 构建，IDEA 仅作为工具补助
