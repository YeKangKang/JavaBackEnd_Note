# Day26 · MySQL（多表、内连接、外连接、子查询）

## 1. 多表查询概述
实际开发中，数据通常分散存储在多个表中。若需要在同一个 `SELECT` 语句中查询多个表的相关信息（如员工所属部门），就必须进行**多表连接查询**。常见的连接方式包括：

- **内连接（`INNER JOIN`）**
- **外连接（`LEFT/RIGHT OUTER JOIN`）**

---

## 2. 内连接（`INNER JOIN`）
内连接（`INNER JOIN`）只返回**两张表中连接字段匹配成功的行**，也就是满足连接条件的交集数据。

### 2.1 隐式内连接
```sql
SELECT 字段名 FROM 表1, 表2 WHERE 条件;
```
> 使用逗号连接表 + `WHERE` 指定连接条件，语义混淆，结构不清晰。

### 2.2 显式内连接（推荐）
```sql
SELECT 字段名
FROM 表1
[INNER] JOIN 表2 ON 连接条件
[INNER JOIN 表3 ON 连接条件3]
...
```
> 使用 `INNER JOIN ... ON` 明确描述连接关系。

### 2.3 搭配 WHERE 进一步筛选
```sql
SELECT 字段名
FROM 表1
[INNER] JOIN 表2 ON 条件 -- ON 处理连接判断条件
WHERE 过滤条件; -- WHERE 处理过滤逻辑
```
> `ON` 负责建立**连接关系**（如字段匹配）

> `WHERE` 用于**进一步筛选**已连接成功的结果集

---

## 3. 外连接（`OUTER JOIN`）
**保留一侧所有记录**，即使连接不成功，另一侧字段也会以 `NULL` 补齐。**适用于主表数据不可漏的场景**。

### 3.1 左外连接（`LEFT [OUTER] JOIN`）
```sql
SELECT 字段名
FROM 表1
LEFT JOIN 表2 ON 连接条件;
```
> 保留左表全部行，右表匹配不到则补 `NULL`。

### 3.2 右外连接（`RIGHT [OUTER] JOIN`）
```sql
SELECT 字段名
FROM 表1
RIGHT JOIN 表2 ON 连接条件;
```
> 保留右表全部行，左表匹配不到则补 `NULL`。

### 示例：
```sql
SELECT e.name, d.name
FROM employee e
LEFT JOIN dept d ON e.dept_id = d.id; -- 查询所有员工及其对应部门
```
> 即使 `employee` 表中某些员工未分配部门，也会保留这些员工的记录，部门字段显示为 `NULL`。

---

## 4. 子查询（Subquery）
子查询是嵌套在其他 SQL 中的 `SELECT`，其结果用于外层查询的条件或数据来源。

> 💡 子查询会先执行，结果作为外层输入。

### 4.1 按返回结构分类

| 类型         | 返回结构   | 常用位置      | 常配关键字             |
|--------------|------------|----------------|------------------------|
| 标量子查询   | 一行一列 `(1x1)` | `WHERE`, `SELECT` | `=`, `>`, `<`, `!=`     |
| 列子查询     | 多行一列 `(nx1)` | `WHERE`        | `IN`, `ANY`, `ALL`     |
| 行子查询     | 一行多列 `(1xn)` | `WHERE`, `SELECT` | `(a, b) = (...)`       |
| 表子查询     | 多行多列 `(mxn)` | `FROM`         | 作为临时表参与连接查询   |

> 所有**子查询本质上返回一张临时表**。能否嵌入主查询，关键在于其**结构是否匹配使用场景**（行列数量、比较位置与方式需一致）。

---

## 5. 子查询示例

### 5.1 标量子查询（1×1）
```sql
SELECT * FROM employee
WHERE salary = (SELECT MAX(salary) FROM employee);  -- 查找工资等于全公司最高工资的员工
```

### 5.2 列子查询（n×1）
```sql
SELECT * FROM employee
WHERE dept_id IN (
  SELECT id FROM dept WHERE name IN ('开发部', '财务部')  -- 查询“开发部”和“财务部”的员工
);
```

### 5.3 行子查询（1×n）
```sql
SELECT * FROM employee
WHERE (gender, salary) = (
  SELECT gender, salary FROM employee WHERE name = '小明'  -- 查询与“小明”性别、薪水相同的员工
);
```

### 5.4 表子查询（n×m）
```sql
SELECT *
FROM (
  SELECT * FROM employee WHERE join_date >= '2017-01-01'  -- 查询 2017 年及以后入职的员工
) e
LEFT JOIN dept d ON e.dept_id = d.id;  -- 左连接补全员工的部门信息
```
> 此处也可以直接使用 `FROM employee, dept` 连接，但由于涉及多表查询，建议优先使用**显示内连接**或**外连接**。若需保留未分配部门的员工，应采用 `LEFT JOIN`；若只关心匹配成功的记录，可使用 `INNER JOIN`。

---

## ✅ 总结
- 内连接只保留匹配成功的数据，结构清晰建议使用显式写法。
- 外连接适用于“主表数据必须保留”的场景。
- 子查询按结构可分为标量、列、行、表子查询。
- 所有子查询本质都是临时结果表，是否能被使用关键看结构匹配。
