# Day25 · MySQL（DCL、用户管理、权限控制）

## 1. DCL 概述

在一个 DBMS 中可能存在多个数据库，每个数据库负责不同项目。为了管理用户与访问权限，MySQL 提供了数据控制语言（DCL：Data Control Language）。

---

## 2. 用户管理

- **查询用户**

  ```mysql
  USE mysql; -- 导航至 mysql 系统数据库
  SELECT * FROM user; -- 查询所有用户信息
  ```

  > **用户信息保存在 `mysql.user` 表中**。`User` 与 `Host` 字段共同决定用户的唯一标识（格式为 `'用户名'@'主机名'`）

- **创建用户**

  ```mysql
  CREATE USER '用户名'@'主机名' IDENTIFIED BY '密码';
  ```

  > 主机名可用 `%` 通配，密码可为空（允许无密码登录）

- **修改用户密码**

  ```mysql
  SET PASSWORD FOR '用户名'@'主机名' = PASSWORD('新密码'); -- 使用加密函数方式
  ALTER USER '用户名'@'主机名' IDENTIFIED WITH 插件 BY '新密码'; -- 使用加密插件方式（更安全）
  ```

  > 推荐使用插件方式，更灵活安全

- **删除用户**

  ```mysql
  DROP USER '用户名'@'主机名';
  ```

  > 一旦删除，该用户将无法再登录数据库系统

## 3. 权限控制

### 3.1 常见权限类型

| 权限名          | 权限描述                   |
| --------------- | -------------------------------- |
| **`GRANT OPTION`** | 授权他人权限的权限               |
| **`ALL`** / **`ALL PRIVILEGES`** | 所有权限集合              |
| **`SELECT`**    | 查询数据                     |
| **`INSERT`**    | 插入数据                     |
| **`UPDATE`**    | 修改数据                     |
| **`DELETE`**    | 删除数据                     |
| **`ALTER`**     | 修改表结构                   |
| **`DROP`**      | 删除数据库/表/视图           |
| **`CREATE`**    | 创建数据库/表                |

> `GRANT OPTION` 限定授权范围，**只能转授自己已有权限的同一作用域**，不能越权。

---

- **查询权限**

  ```mysql
  SHOW GRANTS FOR '用户名'@'主机名'; -- 显示用户当前拥有的所有权限
  ```
  
- **授予权限**

  ```mysql
  GRANT 权限列表 ON 数据库.表 TO '用户名'@'主机名'; -- 赋予权限
  GRANT 权限列表 ON 数据库.表 TO '用户名'@'主机名' WITH GRANT OPTION; -- 在给定范围内赋予授权权限
  ```
  
  > 支持使用 `数据库.*` 或 `*.*` 指定授权范围
  
- **撤销权限**

  ```mysql
  REVOKE 权限列表 ON 数据库.表 FROM '用户名'@'主机名'; -- 撤销权限
  REVOKE GRANT OPTION ON 数据库.表 FROM '用户名'@'主机名'; -- 撤销给定范围内的授权权限
  ```
  
  > `REVOKE` 为幂等操作，撤销不存在权限不会导致报错

---

## ✅ 总结

- 使用 `CREATE USER`、`DROP USER` 管理账号
- 用 **`GRANT` 赋权**，用 **`REVOKE` 撤权**
- 权限范围可通过 `数据库.表` 精准控制
- `GRANT OPTION` 赋予用户再次授权能力
- 权限默认对 `用户名@主机名` 绑定，需同时指定
