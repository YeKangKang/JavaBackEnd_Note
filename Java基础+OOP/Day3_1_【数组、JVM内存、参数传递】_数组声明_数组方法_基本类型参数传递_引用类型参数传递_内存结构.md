# Day3 · 数组、参数传递与内存机制

本节覆盖 Java 中数组结构、参数传递行为以及 JVM 的基础内存模型。

---

## 1. 数组基础

### 1.1 数组定义与特点

- 数组是固定大小、**元素类型一致**的数据容器
- 声明时长度必须确定
- 数组类型为引用类型，使用 `new` 关键字分配堆内存
- 元素会被初始化为该类型的默认值（非垃圾值）

### 1.2 数组的三种声明方式

#### ✅ 指定长度创建（默认值）

```java
int[] arr = new int[5];
```

- 创建一个长度为 5 的整型数组
- 每个元素默认初始化为 `0`

------

#### ✅ 直接赋初始值（静态初始化）

```java
int[] arr = {1, 2, 3, 4};
```

- 创建并初始化数组

------

#### ✅ 使用 `new` + 初始化

```java
int[] arr = new int[]{1, 2, 3, 4};
```

- 和上面静态初始化等效，但更显式

---

### 1.3 数组常用属性与操作

| 操作                   | 示例                       | 说明                     |
|------------------------|----------------------------|--------------------------|
| 获取数组长度           | `arr.length`               | 注意无括号，非方法       |
| 访问元素               | `arr[0]`                   | 下标从 0 开始            |
| 赋值                   | `arr[1] = 42;`             | 修改指定下标的值         |
| 遍历数组（for）        | `for (int i=0; i<arr.length; i++)` | 常用遍历方式     |
| 遍历数组（增强 for）   | `for (int val : arr)`      | 仅用于读取，不修改       |

> ✅ 数组一旦创建，长度不可变。下标范围：`0 ~ length - 1`

---

## 2. 数组相关错误

| 异常类型               | 场景说明                           |
|------------------------|------------------------------------|
| `ArrayIndexOutOfBoundsException` | 访问了非法下标，如 `arr[-1]` 或 `arr[arr.length]` |
| `NullPointerException` | 对一个为 `null` 的数组引用操作    |

> 建议对数组引用进行非空判断后再操作。

## 3. 参数传递机制

Java 的方法参数一律采用**值传递**，但根据参数类型不同，其行为有所区别：

### 3.1 基本类型（`int`、`double` 等）

- 传入的是**值的副本**
- 方法内部修改形参，不影响实参原值

```java
int a = 5;
modify(a);      				// 方法内修改无效
System.out.println(a); 	// 输出仍为 5
```

> 方法中的 `x` 与 `a` 无关，仅是值的复制

------

### 3.2 引用类型（数组、对象等）

- 传入的是**引用地址的副本**
- 方法内部可通过引用修改对象的属性、内容等

```java
int[] a = {1, 2, 3};
modify(a);      					// 方法内修改有效
System.out.println(a[0]); // 输出被修改后的值
```

> 引用类型传的是地址副本，指向同一堆内存
>
> 若方法内部**重新赋值引用变量本身**，则不会影响原对象（引用被覆盖）

---

## 4. JVM 内存结构（基础）

| 区域名称       | 功能说明                                      |
|----------------|-----------------------------------------------|
| 寄存器         | CPU 层使用，与 Java 开发无关                  |
| 方法区         | 存放类结构、常量等                            |
| 栈内存（栈）   | 方法执行期间的局部变量、调用记录              |
| 堆内存（堆）   | 存放通过 `new` 创建的对象、数组               |
| 本地方法栈     | 与本地系统接口有关                            |

---

### 4.1 栈与堆示意

- 基本类型：值直接存在栈中
- 引用类型：栈中保存**堆中数据地址**

```java
int[] arr = new int[3];
```

- **`arr`（引用）**保存在**栈**中
- **`new int[3]`** 实际数组存在于**堆**中
- 修改 `arr[0]` 等价于修改堆内该地址的数据

> 方法执行完毕后，栈帧自动销毁；堆内数据由 JVM 垃圾回收机制管理。
---

## ✅ 总结：Day3 知识回顾

- **数组**：固定长度、类型统一、索引访问，具备内置默认初始化行为
- **参数传递**：Java 全为值传递，但引用类型传递的是地址副本，能修改原始内容
- **JVM 内存结构**：理解栈与堆的分工是掌握对象与引用管理的基础
