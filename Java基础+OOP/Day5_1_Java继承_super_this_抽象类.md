# Day5 · 面向对象进阶（继承、super、this、抽象类）

本节内容聚焦 Java 面向对象三大特征中的“继承”部分，并引入 `super`、`this`、抽象类等机制，为下一节的多态与接口奠定基础。

---

## 1. 面向对象三大特征回顾

Java 面向对象三大特征：

- 封装（Encapsulation）
- 继承（Inheritance）🔰【本节】
- 多态（Polymorphism）

---

## 2. 继承（Inheritance）

### 2.1 背景

多个类可能具有相同的属性和行为（如 `Man` 与 `Woman` 都属于 `Person`），此时可将公共部分抽取到一个父类中，其他类继承该父类以实现代码复用。

> “子类 is a 父类”：继承是一种“从属关系”

---

### 2.2 概念与定义

- 继承是子类获得父类成员（变量/方法）的一种机制。
- 子类可直接使用父类的**非 private 成员**，从而提高代码复用性。
- Java 使用 `extends` 关键字声明继承关系：

```java
class Parent { }
class Child extends Parent { }
```

---

### 2.3 Java 的继承特性

| 特性 | 说明 |
|------|------|
| 单继承 | Java **只支持单继承**，一个类只能有一个直接父类 |
| 多层继承 | 支持继承链：`Object ← A ← B ← C` |
| 最终根类 | 所有类最终都继承自 `java.lang.Object` 类 |

---

## 3. 成员继承与访问规则

### 3.1 成员变量继承

- 父类的所有成员变量都会被子类继承，但 `private` 成员在子类中不可直接访问
- 若子类定义了**同名变量**，则会**隐藏**父类的变量

```java
public class Parent {
    public int num = 1;
}

public class Child extends Parent {
    public int num = 2;

    public void showNums() {
        System.out.println(this.num);   	// 2，子类的 num
        System.out.println(super.num); 		// 1，父类的 num
    }
}
```

> `this.num` 指向子类变量
> `super.num` 可用于访问父类的被隐藏变量

---

### 3.2 成员方法继承

- 子类会继承父类的所有非 `private` 成员方法；`private` 方法不会被继承，在子类中完全不可见
- 如果子类定义了**同名方法**，需区分是否构成**重写（Override）**

#### ✅ 构成重写的条件：

| 判断维度 | 要求 |
|----------|------|
| 方法名   | 必须相同 |
| 返回类型 | 必须相同或为父类返回类型的子类（协变） |
| 参数列表 | 类型、顺序、个数完全一致 |
| 访问权限 | 子类权限必须 ≥ 父类（如父类是 `protected`，子类不能是 `private`） |

> 只有当**方法名**、**返回值类型**、**参数列表**（类型、顺序、个数）完全一致，且**访问权限不低于父类方法**时，才构成重写（Override）
>
> 建议加上 `@Override` 注解，增强可读性并防止误写

---

### 3.3 static 成员（变量与方法）的特性

- `static` 成员属于**类本身**，而不是对象实例
- 可以被子类继承，但若子类定义了同名的 `static` 成员，会发生**隐藏（而非重写）**
- `static` 成员不参与多态，**访问行为取决于引用变量的类型**，而不是实际对象类型

```java
public static void greet() { } // 父类与子类同名 static 方法无重写关系
```

## 4. 构造方法与继承

### 4.1 构造方法不会被继承

构造方法仅供本类内部用于初始化，不会被子类继承。

---

### 4.2 子类构造器必须先调用父类构造器具

- 若父类有无参构造方法，子类构造器会默认调用 `super()`
- 若父类只有有参构造器，子类**必须显式**使用 `super(...)` 调用，否则编译错误

```java
class Parent {
    public Parent(String name) { }
}

class Child extends Parent {
    public Child() {
        super("Tom"); // 必须手动调用
    }
}
```

---

### 4.3 `super(...)` 与 `this(...)` 的调用规则

你可以在**多个构造器中使用 `this(...)` 构造器链**，但：

- 在构造器调用链中，最外层构造器的第一行必须是 `super(...)`，以确保父类对象在子类构造执行前先被初始化
- 且 `this(...)` 和 `super(...)` **永远不能同时出现在同一个构造器中**

> 一个构造方法中只能调用一次构造器，并且必须是第一行。不能在同一个构造方法中同时调用 `super(...)` 和 `this(...)`，否则编译错误。构造器重载时，最终必须确保调用到父类构造器。

---

## 5. super 与 this 关键字

### 5.1 super 关键字

`super` 关键字表示**对父类对象的引用**，用于访问当前类从父类继承的成员（变量、方法或构造器）。

| 用法 | 示例 | 说明 |
|------|------|------|
| 访问父类变量 | `super.name` | 子类与父类变量重名时访问父类变量 |
| 调用父类方法 | `super.work()` | 子类方法重写后仍想访问父类方法 |
| 调用父类构造器 | `super(...)` | 必须在构造方法第一行使用 |

---

### 5.2 this 关键字

`this` 关键字表示**当前对象自身的引用**，即方法或构造器所在对象的实例本身。

| 用法 | 示例 | 说明 |
|------|------|------|
| 访问本类变量 | `this.name` | 当前对象的变量引用 |
| 调用本类方法 | `this.show()` | 当前对象的方法调用 |
| 构造器内部调用 | `this(...)` | 构造器重载内部跳转 |

---

## 6. 抽象类与抽象方法

### 6.1 概念与格式

- 抽象方法：没有方法体，用 `abstract` 修饰
- 抽象类：包含抽象方法的类，必须用 `abstract` 修饰

```java
public abstract class Animal {	// 抽象类
    public abstract void run(); // 抽象方法
}
```

---

### 6.2 使用规则

- 抽象类不能实例化
- 子类必须实现所有抽象方法，否则子类也必须声明为抽象类
- 抽象类可以包含**普通方法**、**成员变量**、**构造方法**等

---

### 6.3 特殊说明

| 规则 | 说明 |
|------|------|
| 抽象类中可无抽象方法 | 可用于限制实例化或作为模板设计 |
| 抽象方法不能有方法体 | 写成 `public void run();` 会报错，必须加 `abstract` |
| 抽象类可以有构造函数 | 抽象类可定义构造器，供子类初始化父类成员 |

---

## ✅ 小结

- 继承是实现代码复用与多态的基础
- 子类只能继承一个直接父类，但最终都继承自 `Object`
- `super` 与 `this` 是构造链与成员访问的关键
- 抽象类无法实例化，但可作为规范与模板使用
- 构造器不会被继承，必须主动调用父类构造器完成初始化
