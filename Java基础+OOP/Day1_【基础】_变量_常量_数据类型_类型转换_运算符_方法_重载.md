## 1. Java 程序结构与运行机制

### 1.1 Java 开发三步流程

1. **编写源代码**（.java 文件）
2. **编译为字节码**：使用 `javac` 编译器生成 `.class` 文件
3. **运行程序**：通过 `java` 命令调用 JVM 执行 `.class` 文件

### 1.2 JVM、JRE、JDK 区别

| 组件 | 全称 | 含义 | 用途 |
|------|------|------|------|
| `JVM` | Java Virtual Machine | Java 程序的运行虚拟环境 | 执行字节码 |
| `JRE` | Java Runtime Environment | 包含 JVM + 核心类库 | 用于运行程序 |
| `JDK` | Java Development Kit | 包含 JRE + 编译器、调试器等工具 | 用于开发程序 |

## 2. HelloWorld 示例分析

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

- `public class HelloWorld`：Java 程序入口类，类名需与文件名一致。
- `main()`：程序主入口方法，由 JVM 调用。
- `System.out.println()`：标准输出语句。

## 6. 常量与变量

### 6.1 常量

固定不变的值，如 `123`、`true`、`'A'`、`"Hello"`，或通过 `final` 声明的变量，常量储存在JVM**方法区的常量池**中。

### 6.2 变量声明与赋值

```java
int a;										// 声明一个整形变量 a，但是需要赋值后才能使用
float pi = 3.14F;					// 浮点数需要在末尾加F和double类区分
long distance = 123456L;	// 长整型需要加L于int区分
```

- 声明变量需指定类型
- **局部变量**必须赋值后才能使用（否则会报错），**成员变量**和 **静态变量**则会自动初始化。

## 8. 类型转换

### 8.1 自动类型转换（小 → 大）

遵循如下顺序：`(byte, short, char) → int → long → float → double`

```java
int a = 5;
double d = a; // 自动提升为 double
```

⚠️ 在 Java 中，**`byte`、`short`、`char` 在参与运算时都会自动提升为 `int` 类型**

- `byte + byte → int`
- `char + short → int`
- `byte + char → int`

即使两个操作数是同一类型，也会统一转换为 `int` 后再参与运算。

```java
byte a = 1;
byte b = 2;
// byte c = a + b; // ❌ 编译错误：a + b 为 int，不能直接赋值给 byte
int c = a + b;     // ✅ 正确
```

### 8.2 强制类型转换（大 → 小）

```java
double pi = 3.14;
int x = (int) pi; // x = 3，丢失精度
```

> 强转时需手动加括号，可能损失精度或溢出

### 9.1 短路逻辑运算符详解

短路逻辑运算：一旦逻辑运算符左侧表达式已满足判断条件，短路逻辑运算符将**立即返回判断结果**，并跳过右侧表达式的执行。

- `&&`：左侧为 `false` 则直接返回 `false`，右侧不再执行
- `||`：左侧为 `true` 则直接返回 `true`，右侧不再执行

```java
// 非短路运算符，即使 user 为 null 也会运行 user.isActive()
if ( user != null & user.isActive() ) {...}	// 抛出 NullPointerException

// 短路运算符，当左侧满足判断则返回 false，不再运行 user.isActive()
if ( user != null && user.isActive() ) {...}	// 没有异常
```
> 短路机制不仅用于逻辑判断，也常用于条件执行、兜底赋值等语法糖优化

### 9.2 自增/自减运算符详解

`++` / `--` 有前缀与后缀形式，参与表达式时顺序不同：

- **后缀自增 `a++`**：先使用原值，再自增（结果返回原值）
- **前缀自增 `++a`**：先自增，再使用（结果返回新值）

例如：

```java
int a = 10;
int b = a++ + ++a; // 10 + 12 = 22，a最终为12
```

> 后缀 `a++` 在表达式中使用后即自增，不是“整行结束后再变”。

## 10. 方法

### 10.1 方法结构

```java
public static int add(int a, int b) {
    return a + b;
}
```

- `public`：访问修饰符
- `static`：静态方法（可直接调用，非`static`意味着该方法只能被类的实例调用）
- `int`：返回值类型
- `add`：方法名
- `(int a, int b)`：参数列表
- `return`：返回执行结果

#### main 方法说明

```java
public static void main(String[] args) { ... }
```

- 程序入口，由 JVM 自动调用
- 参数为命令行参数数组

#### 方法调用规则

- 必须显式调用才能执行
- 参数按值传递，作用域在方法体内
- 方法定义顺序不影响执行

---

### 10.2 方法重载（Overloading）

Java 支持同名方法通过不同参数列表实现重载：

| 判断维度     | 是否构成重载 | 示例 |
|--------------|---------------|------|
| 参数个数     | ✅            | `add(int)` vs `add(int, int)` |
| 参数类型     | ✅            | `print(int)` vs `print(String)` |
| 参数顺序     | ✅            | `f(int, double)` vs `f(double, int)` |
| 参数名不同   | ❌            | 无影响 |
| 返回值不同   | ❌            | 无法区分重载 |

```java
void print(int a) { }
void print(String s) { } // 合法重载
```
